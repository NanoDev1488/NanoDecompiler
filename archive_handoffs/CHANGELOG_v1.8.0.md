# v1.7.8 «Точность» → v1.8.1

Сводный changelog сразу за 4 версии — между v1.7.3 и этим файлом
отдельные CHANGELOG_v1.7.x.md для 1.7.4-1.7.7 не велись (см. историю в
HANDOFF-файлах), а с 1.7.8 по 1.8.1 changelog вообще не заводился, хотя
накопилось много реальных фиксов, найденных на присланных пользователем
jar'ах — восполняем пробел одним файлом, а не задним числом плодим 4.

## v1.7.8 «Точность»

- **Paper/Paperclip-загрузчики (`paper-*-nanocore.jar`) не декомпилировались
  вообще** (0 файлов из 0 методов). Причина: известная библиотека
  `paper-api` матчилась по префиксу `io.papermc` целиком — это ловило
  вообще любой подпакет `io.papermc.*`, включая сам код Paperclip-
  загрузчика. Сузили до `io.papermc.paper`.
- Та же проблема тянула за собой **META-INF/libraries + META-INF/versions
  раздували вывод на десятки-сотни МБ** бинарными копиями чужого
  maven-кэша зависимостей сервера — теперь отфильтровываются.
- **pom.xml генерировался даже для файлов без единого манифеста платформы**
  (например, самописных инструментов, не Minecraft-плагинов) — и врал в
  комментарии, что источник — `plugin.yml`, которого не было. Теперь
  pишется только если это настоящий оригинал внутри jar или платформа
  опознана хоть как-то.
- Список пропущенных библиотечных классов в GUI (10+ библиотек) больше не
  голый список на всю ширину модалки — сворачивается.
- Детальные строки малварь-находок в консоли красились как обычный `info`
  вместо `warning` — теперь ловятся отдельно от заголовка блока.

## v1.8.0

- **CI ломался на всех трёх платформах** (`"Github" is not exported by
  lucide-react`) — брендовая иконка вместо генерик-UI-иконки была
  чувствительна к минорным обновлениям библиотеки. Заменена на
  собственный инлайн-SVG.
- `new T[N]; x[0]=..; x[1]=..;` (байткод-форма создания массива, особенно
  часто в reflection/varargs-коде вроде `Method.invoke`) теперь
  схлопывается в компактный литерал `new T[]{..}`.
- Обфускация имён методов/полей, спрятанная за `$` (раньше ЛЮБОЙ `$` в
  имени безусловно означал "не обфусцировано"), теперь ловится — если
  это не известный javac-синтетический паттерн (`lambda$x$0`,
  `access$N`, `this$N`, `val$N`).
- Движок теперь честно сообщает о найденных ВЛОЖЕННЫХ jar (см.
  `embedded_jars` в JSON-выводе) вместо молчаливого копирования их как
  обычного бинарного ресурса. Рекурсивная декомпиляция вложенных jar
  по-прежнему не реализована — отдельная большая фича.
- Цветовая подсветка в вьюере теперь ловит не только явные
  `ChatColor`/сырые §-коды, но и кастомные методы форматирования текста
  (например `FancyFont.stylize(...)`), если они идут в конкатенации сразу
  после части строки с уже известным цветовым сигналом.

## v1.8.1

- Collapse/expand-состояние дерева файлов теперь переживает перезапуск
  приложения — тем же способом, что уже был сделан для sortMode.
- Предупреждающая иконка у файла с частичным выводом (⚠) показывала сам
  факт предупреждения, но не текст — почему именно. Добавлен `title`.
- Поиск по дереву файлов проверял только ИМЯ файла, не пакет — искать
  "listener" и не находить файл в пакете `...listener`, если сам файл
  называется иначе, было контринтуитивно. Теперь матчит оба поля.
- Убрана избыточная (и потенциально более широкая, чем нужно) запись
  `com.zaxxer` в таблице известных библиотек — специфичной
  `com.zaxxer.hikari` достаточно.

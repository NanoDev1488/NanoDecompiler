✨ 20 масштабных проходов читаемости AST (ReadUpd 1..20)

В отличие от традиционных декомпиляторов, превращающих байткод в бесконечные цепочки присваиваний и goto, движок NanoDecompiler применяет 20 эвристических оптимизаций:

1. Составные присваивания и автоинкремент
Operators
Байткод / Другие декомпиляторы x = x + 1;
count = count + n;
mask = mask & 255;
NanoDecompiler v1.9.158 x++;
count += n;
mask &= 0xFF;
2. Десугаринг циклов foreach (for-each array)
Loops
Сырой байткод for (int i = 0; i < arr.length; i++) {
  String item = arr[i];
  System.out.println(item);
}
Чистый Java код for (String item : arr) {
  System.out.println(item);
}
3. Уплощение Guard Clause и устранение избыточных else
Nesting Flattening
Глубокая вложенность if (player == null) {
  return false;
} else {
  player.sendMessage("Welcome");
  return true;
}
Плоский Guard Clause if (player == null) {
  return false;
}
player.sendMessage("Welcome");
return true;
4. Умное именование типов Bukkit & Minecraft
Type Inference
Бессмысленные temp-имена Player p1 = event.getPlayer();
World w1 = p1.getWorld();
ItemStack is1 = p1.getItemInHand();
Человекочитаемые идентификаторы Player player = event.getPlayer();
World world = player.getWorld();
ItemStack itemStack = player.getItemInHand();
5. Ликвидация O(N³) узких мест на гигантских Enum-классах (XMaterial)
Performance v1.9.158
Старый алгоритм (Таймаут 500+ сек) // Квадратичный перебор всех 10 000 стейтментов
// Перекопирование вектора на каждое схлопывание
// Зависание на классах с 1000+ константами
Новый алгоритм (< 0.5 сек) // Скользящее окно lookahead = 32
// In-place компактизация и срез count_local_uses_slice
// Мгновенная декомпиляция XMaterial.class

🛡️ 15 стадий конвейера деобфускации

NanoDecompiler справляется с самыми жесткими обфускаторами (Allatori, Zelix KlassMaster, ProGuard, Stringer):

🔤

Allatori XOR дешифровка

Автоматическая нейтрализация 2- и 3-ключевых чередующихся XOR-алгоритмов, инлайнинг вызовов intern(), charAt(), substring().

🌀

Control Flow Unflattening

Расплющивание ложных switch-диспетчеров состояний, декомпозиция запутанных циклов в прямой поток выполнения.

⚖️

Очистка непрозрачных предикатов

Свертка константных тождеств (x ^ y) ^ y == x, вычисление детерминированных условий и удаление мертвых веток.

🪤

Нейтрализация батутов исключений

Сворачивание паразитных конструкций try { throw new E(); } catch (E e) { body; } обратно в чистый код.

🔮

Десугаринг рефлексии

Преобразование вызовов Class.forName().getMethod().invoke() обратно в прямые вызовы Java методов.

📦

Свертка статических таблиц

Распаковка статических массивов <clinit> и подстановка литералов на место зашифрованных обращений по индексам.

📦 Архивы и Фильтрация Ядер Серверов

Встроенный движок распознает и распаковывает сборки любых форматов без внешних утилит:

.JAR / .ZIP

Нативная распаковка через встроенный C++ ZipReader с защитой от ZipSlip и Path Traversal.

.TAR.GZ / .TGZ

Потоковый декомпрессор zlib с моментальным парсингом заголовков ustar.

.7Z / .7ZIP

Высокоскоростное LZMA/LZMA2 извлечение с гарантированной изоляцией от ASAR-окружения.

.RAR

Автономный WebAssembly UnRAR модуль без необходимости устанавливать WinRAR.

🎯 Умный отсев ядер серверов (Zero False Positives)

При распаковке комплексных серверных архивов движок автоматически отсеивает тяжелые файлы ядер (Paperclip, Purpur, Spigot, CraftBukkit, Vanilla bundler, MinecraftServer.class) и декомпилирует исключительно пользовательские плагины с plugin.yml или моды с fabric.mod.json.

📜 История релизов

Декомпилятор активно развивается. Последние ключевые изменения:

v1.9.158 (2026-10-07)

Устранение зависаний, стандартизация артефактов и новый C# GUI:
• Ликвидация O(N³) узких мест: Алгоритмы collapse_temp_chains и inline_crossing_pass оптимизированы скользящим окном lookahead и компактизацией без аллокаций. Классы с 1000+ enum-константами (XMaterial.class) теперь декомпилируются за миллисекунды без таймаутов.
• Стандартизация релизных артефактов: Все бинарники теперь имеют строгий паттерн [Name]-[OS]-[arch]-[version][ext].
• NanoDecompilerLite (C#): Выпущен новый ультралегкий кроссплатформенный клиент на C# / Avalonia с просмотрщиком Java кода и встроенным чекером обновлений.
• Очистка репозитория: Все черновики и старые хэндоффы перемещены в изолированную директорию archive_handoffs/.
• Полный редизайн документации: Современный кибер-стиль с таблицей релизов и описанием всех модулей.

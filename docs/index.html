Честный C++17 декомпилятор
Minecraft-плагинов и модов

NanoDecompiler восстанавливает скомпилированные JAR-файлы в чистый Maven-проект с Java-исходниками, сохраняя структуру пакетов, ресурсы и pom.xml без выдуманного кода.

⚡ Версия: v1.9.156
🚀 100% C++17 Движок (Zero-Python)
🛡️ Полный Офлайн / Без телеметрии
📦 .jar / .zip / .tar.gz / .7z / .rar
🎮 Bukkit · Paper · Velocity · Fabric · Forge

🚀 Быстрый старт

Приложение доступно в виде готовых бинарных сборок или может быть скомпилировано из исходников.

💡 Сборка на слабых системах (1 CPU, 512MB RAM)

C++ движок оптимизирован под низкое потребление ресурсов. Флаги -fno-var-tracking -fno-var-tracking-assignments и параллелизм -j 1 позволяют собирать ядро даже на серверах с 512 МБ оперативной памяти.

# 1. Клонирование репозитория
git clone https://github.com/nanodev/NanoDecompiler.git
cd NanoDecompiler

# 2. Компиляция C++ движка (resources/engine_cpp)
cd resources/engine_cpp
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release -j 1
cd ../..

# 3. Сборка GUI и запуск
npm install
npm run build
npm start

✨ 20 масштабных проходов читаемости (ReadUpd 1..20)

В версии 1.9.155 движок получил 20 специализированных AST-проходов, трансформирующих сырой машинный байткод в идиоматичный, чистый Java-код, словно написанный человеком.

ReadUpd 1: Десугаринг составных присваиваний
AST / Operators
Байткод / Было
x = x + 1;
count = count + n;
mask = mask & 255;
NanoDecompiler / Стало
x++;
count += n;
mask &= 0xFF;
ReadUpd 3: Нормализация булевых условий
Logic Normalization
Байткод / Было
if (active == true && !(ready == false))
if (!(x < 10))
NanoDecompiler / Стало
if (active && ready)
if (x >= 10)
ReadUpd 5: Преобразование while(true) в while(!cond)
Loop Structuring
Байткод / Было
while (true) {
  if (idx >= limit) break;
  process(idx);
}
NanoDecompiler / Стало
while (idx < limit) {
  process(idx);
}
ReadUpd 6 & 7: Уплощение Guard Clause и устранение избыточных else
Nesting Flattening
Байткод / Было
if (player == null) {
  return false;
} else {
  // 50 строк глубокого отступа
}
NanoDecompiler / Стало
if (player == null) {
  return false;
}
// Код идет без лишней вложенности
ReadUpd 8 & 9: Шестнадцатеричные маски и именованные константы
Constants & Masks
Байткод / Было
int max = 2147483647;
double pi = 3.141592653589793;
int rgb = 16777215;
NanoDecompiler / Стало
int max = Integer.MAX_VALUE;
double pi = Math.PI;
int rgb = 0xFFFFFF;
ReadUpd 14: Десугаринг Return-тернарников
Ternary Desugaring
Байткод / Было
if (valid) {
  return "yes";
} else {
  return "no";
}
NanoDecompiler / Стало
return valid ? "yes" : "no";
ReadUpd 16: Группировка Multi-Catch блоков Java 7+
Exceptions / Catch
Байткод / Было
try { ... }
catch (IOException e) { log(e); }
catch (SQLException e) { log(e); }
NanoDecompiler / Стало
try { ... }
catch (IOException | SQLException e) {
  log(e);
}
ReadUpd 17: Умное переименование Bukkit / Java переменных
Type-Aware Renaming
Байткод / Было
Player var1 = event.getPlayer();
Location loc2 = var1.getLocation();
ItemStack o3 = var1.getItemInHand();
NanoDecompiler / Стало
Player player = event.getPlayer();
Location location = player.getLocation();
ItemStack itemStack = player.getItemInHand();
ReadUpd 18: Десугаринг циклов foreach (Enhanced For)
Loop Modernization
Байткод / Было
for (int i = 0; i < items.length; i++) {
  ItemStack item = items[i];
  give(item);
}
NanoDecompiler / Стало
for (ItemStack item : items) {
  give(item);
}

🛡️ 15 этапов конвейера деобфускации (ObfUpd 1..15)

NanoDecompiler нейтрализует современные коммерческие обфускаторы (Allatori, Zelix KlassMaster, ProGuard, Stringer), восстанавливая оригинальную семантику.

🔤

Строковая дешифровка

Расшифровка Allatori двух- и трехключевого чередующегося XOR, свертка обращений intern(), charAt(), substring().

🌀

Control Flow Unflattening

Расплющивание ложных switch-диспетчеров состояний Zelix KlassMaster с трассировкой переходов и устранением фиктивных переменных циклов.

⚖️

Очистка непрозрачных предикатов

Анализ константных тождеств (x ^ y) ^ y == x, удаление ложных веток условий и мертвых блоков.

🪤

Батуты исключений

Нейтрализация конструкций try { throw new E(); } catch (E e) { ... }, превращающих линейный код в спагетти.

🔮

Десугаринг рефлексии

Сворачивание Class.forName().getMethod().invoke() обратно в прямые вызовы Java методов и доступ к полям.

📦

Автобоксинг и Assert

Устранение паразитных вызовов Integer.valueOf() / intValue() и восстановление оператора assert из флагов $assertionsDisabled.

📦 Поддержка архивов и Фильтрация плагинов

NanoDecompiler поддерживает распаковку всех популярных типов архивов с автоматическим извлечением плагинов.

.ZIP / .JAR

Прямая распаковка через встроенный C++ ZipReader и системный движок.

.TAR.GZ / .TGZ

Потоковый декомпрессор zlib с разбором ustar заголовков на лету.

.7Z / .7ZIP

Высокопроизводительное извлечение с защитой от виртуального ASAR-окружения.

.RAR

Автономный WebAssembly движок UnRAR без внешних зависимостей.

🎯 Умный отсев ядер серверов

При распаковке комплексных сборок движок мгновенно идентифицирует ядра (Paperclip, Purpur, Spigot, CraftBukkit, Vanilla bundler, MinecraftServer.class) и пропускает их, фокусируясь исключительно на пользовательских плагинах с манифестами plugin.yml.

🔍 Эвристический Малварь-сканер

Встроенный сканер безопасности выполняет сигнатурный и эвристический анализ байткода на известные паттерны вредоносного ПО:

  • Отправка данных на внешние Discord Webhook'и, Telegram Bot API и неизвестные внешние хосты.
  • Теневая загрузка исполняемых файлов (Runtime.getRuntime().exec(), ProcessBuilder).
  • Скрытая распаковка полезной нагрузки из ресурсов и Base64-строк.
  • Кража сессий, токенов, паролей от базы данных и конфигурационных файлов сервера.

💻 C++ Ядро и CLI-параметры

Декомпилятор может использоваться автономно из консоли в CI/CD пайплайнах без Electron GUI:

# Запуск декомпиляции файла через CLI
./NanoDecompilerCLI --input Plugin.jar --output ./decompiled_src/

# Доступные флаги:
--input <path>       Путь к целевому JAR/архиву
--output <dir>       Директория сохранения Maven-проекта
--lang <ru|en>       Язык логов и комментариев декомпилятора
--parallel <N>       Количество потоков декомпиляции (по умолч. все ядра)
--version            Показать версию декомпилятора

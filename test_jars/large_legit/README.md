# Крупный легитимный плагин — стресс-тест на масштаб + пропуски в библиотечном фильтре

`BukkitOfUtils-1_19_0.jar` (HANDOFF_48) — не малварь, реальный крупный
утилитный плагин (753 класса, 5989 методов). Полезен как:

1. Стресс-тест декомпиляции на масштабе, сильно превышающем остальной
   тестовый корпус (следующий по размеру - Salaires, 3020 классов ДО
   фильтрации, но всего 14 своих после; здесь 618 "своих" классов после
   фильтрации - на порядок больше типового плагина).
2. Регрессия для `known_libs()` (`pom_builder.cpp`) - на нём нашлись 4
   реальных пропуска в таблице известных библиотек (`org.json`,
   `org.opentest4j`, `org.intellij.lang.annotations` как второй пакет
   уже известного `org.jetbrains:annotations`, `mc.obliviate.*` -
   см. HANDOFF_48). Ожидаемо: `library_classes_skipped` = 180
   (45 старых + 135 новых), 618 классов остаётся на декомпиляцию.

**НЕ добавлено в исключения**: пакет `gg/drak/thebase` (416 классов,
59% оставшегося кода) - потенциально личный переиспользуемый фреймворк
автора плагина (Drak), а не сторонняя библиотека - недостаточно
уверенности, чтобы исключать (риск молча спрятать реальную логику
плагина хуже риска показать лишний вендоренный код). См. обсуждение в
HANDOFF_48, если появятся более веские основания (напр. точное
совпадение с публично известной библиотекой) - можно пересмотреть.

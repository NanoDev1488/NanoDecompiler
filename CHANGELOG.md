# NanoDecompiler Changelog

## [1.9.115] - 2026-09-30

### C++ Декомпилятор (Engine)
- **Исправление нестандартных паттернов создания объектов/конструкторов (`<init>`)**:
  - Устранена ошибка `DecompileAbort: unrecognized <init> pattern`.
  - Реализована безопасная обработка конструкторов без сохранения результата (`new Foo(...)` как выражение-оператор).
  - Корректная декомпиляция вызовов конструкторов на предсохранённых локальных переменных и нетривиальных выражениях (`Assign`).
- **Синтез отсутствующих значений стека без предшественников**:
  - Устранена ошибка `унаследованное значение стека без предшественников`. При нехватке стека на блоках без предшественников генерируются типизированные псевдопеременные `__tempA`, позволяя декомпилятору продолжить разбор метода.
- **Разрешение нередуцируемых переходов внутри регионов CFG**:
  - Устранена ошибка `нередуцируемый переход внутри региона`. Вместо аварийного отката метода на байткод, циклы в нередуцируемых графах аккуратно прерываются с генерацией перехода `GotoStmt`.
- **Ликвидация несогласованной глубины пересечения стека**:
  - Замена строгого равенства на `>=` в `ensure_depth`, устраняющая откат на сложных тернарных/массивных выражениях (`arr[i] = cond ? a : b`).

### GUI & Модуль обновлений (Updater)
- **Реальный процент загрузки нового клиента и движка**:
  - Добавлено отслеживание байтов (`downloaded` / `total`) в реальном времени с выводом мегабайт и точного процента (`XX% (X.X / Y.Y MB)`).
  - Плавный анимированный прогресс-бар в окне обновлений.
- **Выбор варианта обновления**:
  - Добавлена возможность скачать и обновить **только C++ движок (CLI)** отдельно, без необходимости переустанавливать всё приложение.
  - Сохранена кнопка полного обновления клиента при выходе новых версий GUI.
- **Отображение Changelog**:
  - Окно обновлений теперь автоматически загружает и красиво форматирует список изменений текущего релиза из GitHub Release.
  - GitHub Actions пайплайн автоматически извлекает соответствующую секцию из `CHANGELOG.md` для каждого релиза.

## [1.9.114] - 2026-09-30

### C++ Декомпилятор (Engine)
- **Многоуровневое устранение сбоев пересечения стека (Multi-depth Stack Crossing)**:
  - Устранена ошибка `DecompileAbort: двойное пересечение стека не поддерживается`.
  - Добавлен итеративный алгоритм каскадного связывания временных переменных (`canonical`) из блоков-предшественников при глубине стека до 16 элементов.
- **Безопасное сохранение остатков стека**:
  - Устранена ошибка `неразрешённый остаток на стеке в блоке X`.
  - Выходные значения стека, не поглощённые последующими инструкциями, сохраняются в типизированные локальные переменные `__tempX`, предотвращая аварийный откат декомпиляции всего метода на байткод.

### Телеметрия и отчёты
- **Автоматическая отправка телеметрии включена по умолчанию**:
  - В настройках `telemetryEnabled: true` по умолчанию.
  - При возникновении fallbacks автоматически отправляется подробный багрепорт с содержимым `README_RU.txt` и контекстом байткода на сервер телеметрии.

## [1.9.113] - 2026-09-29

### C++ Декомпилятор (Engine)
- **Восстановление непосещённых достижимых CFG блоков**:
  - Реализован метод `recover_unconsumed_blocks` в `Structurer::build`, предотвращающий потерю блоков при вложенных ветвлениях.
- **Разрешение переходов в try-catch блоках**:
  - Добавлена поддержка trampoline `goto` переходов внутри `build_try`.
- **Корректная проверка полноты покрытия (`check_full_coverage`)**:
  - Блоки с инструкцией `return;` корректно обрабатываются как безопасные терминальные точки.

## [1.9.112] - 2026-09-29

### C++ Декомпилятор (Engine)
- **Исправление утечки локальных переменных**:
  - Метод `hoist_escaping_locals` изолирует дочерние области видимости от загрязнения родительских списков `declared_so_far`.
  - Реализован `hoist_all_escaping_to_root` для безопасного выноса конфликтующих объявлений переменных на уровень метода.

### GUI & Настройки
- Восстановлены параметры телеметрии в `SettingsModal` и `engine.tsx`.

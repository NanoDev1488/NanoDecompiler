# NanoDecompiler telemetry relay

Мини-сервер: принимает отчёты об ошибках от NanoDecompiler (`POST /report`)
и пересылает их тебе в Telegram — коротким текстовым сообщением-summary +
файлом с полным контекстом каждого отката на байткод (10 строк до, сам
байткод, 10 строк после — именно в таком порядке для каждого случая).

Без npm-зависимостей — только Node.js 18+ (нужен встроенный `fetch`).

## Установка

1. Скопировать `config.example.json` в `config.json`, заполнить:
   - `botToken` — токен бота от [@BotFather](https://t.me/BotFather);
   - `chatId` — твой личный chat id (см. ниже, как узнать);
   - `port` — на каком порту слушать (по умолчанию 8787);
   - `reportSecret` — необязательно: если задать, клиент должен присылать
     тот же секрет в заголовке `X-Report-Secret`, иначе сервер отклонит
     запрос. Пусто — сервер принимает любой `POST /report` без проверки.

   Вместо `config.json` можно задать переменные окружения
   `TG_BOT_TOKEN` / `TG_CHAT_ID` / `PORT` / `REPORT_SECRET` — они в
   приоритете над файлом.

2. Запуск:
   ```bash
   node server.js
   ```

3. В настройках NanoDecompiler указать адрес телеметрии:
   `http://<ip-или-домен-сервера>:<port>/report`.

## Как узнать свой chat id

1. Написать созданному боту любое сообщение (просто открыть с ним чат и
   отправить "привет").
2. Открыть в браузере:
   `https://api.telegram.org/bot<TOKEN>/getUpdates`
3. В ответе найти `"chat":{"id": ЧИСЛО, ...}` — это и есть `chatId`.

## Держать сервер живым (по желанию)

Простейший вариант — `pm2` или systemd-юнит; для одного личного сервера
достаточно и `nohup node server.js &` / `screen`/`tmux`.
